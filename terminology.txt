# Образ
Неизменяемый шаблон или "слепок" для создания контейнеров. 
Содержит код приложения, библиотеки, зависимости и базовую ОС. Состоит из слоев.

# Контейнер
Запущенный экземпляр образа. Изолированная среда со своей файловой системой, процессами и сетью. 
Контейнер можно запускать, останавливать и удалять.

# Dockerfile
Текстовый файл с пошаговыми инструкциями для сборки Docker-образа. 
Описывает, какую базовую систему взять, какие файлы добавить, какие команды выполнить и что запустить при старте.

# Реестр (Registry)
Хранилище Docker-образов. Самый известный публичный реестр — Docker Hub. 
Позволяет скачивать готовые образы или загружать туда свои собственные.

# Том (Volume)
Специальная область на диске хоста для хранения данных контейнера. 
Тома не удаляются вместе с контейнером, что позволяет сохранять важные данные при его пересоздании

# Сеть (Network)
Виртуальная сеть для связи контейнеров между собой и с внешним миром. 
Позволяет изолировать сервисы или открыть им доступ друг к другу по внутренним DNS-именам.

# Docker Compose
Утилита для управления приложениями, состоящими из нескольких контейнеров. 
С помощью YAML-файла описывает все сервисы, их настройки, сети и тома, позволяя запускать весь стек одной командой.

# Docker Engine
Основная часть Docker, работающая по архитектуре клиент-сервер. 
Включает фоновый процесс-демон (управляет объектами), REST API и CLI (командную строку для пользователя).

# Тег (Tag)
Метка версии или варианта образа. Например, в nginx:alpine тегом является alpine. 
Если тег не указан, Docker использует latest.

# Слой (Layer)
Фрагмент файловой системы образа. Каждая инструкция в Dockerfile создает новый слой. 
Слои кэшируются и переиспользуются в других образах, что экономит место и ускоряет сборку.
